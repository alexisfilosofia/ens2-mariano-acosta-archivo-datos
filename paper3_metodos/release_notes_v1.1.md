# Release notes: v1.1-paper3

This corrective release supersedes `v1.0-paper3` for scientific use.

The global validation totals reported in v1.0 were correct:
1,867 matches over 1,980 comparisons (94.29%).

Version 1.1 corrects the public aggregate distributions by field and year,
which had been incorrectly reconstructed during sanitization of v1.0.

It also correctly associates the audited 95% bootstrap interval
(92.70%-95.98%, 5,000 stratified replicates)
with the annual-composition-weighted estimate of 94.41%.

No identifiable or row-level data are added in this corrective release.
